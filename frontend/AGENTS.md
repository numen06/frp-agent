# 前端界面规范

- 统一使用 shadcn-vue（`src/components/ui`）与 Tailwind；用户已明确要求移除 Flowbite 和旧定制控件。不要维护第二套 UI 框架或兼容选择器，全局主题在 `src/assets/index.css` 维护。
- 下拉选择使用 shadcn-vue Select，远程检索使用基于 shadcn-vue Combobox 的业务组件；菜单、弹窗和侧栏使用其 DropdownMenu、Dialog、Sidebar / Sheet。禁止自行实现浮层定位、焦点管理或键盘选择。
- 页面使用 `PageHeader`，一个页面只保留一个一级标题；标题、说明和主要操作保持相同结构。列表容器使用 `Card`，筛选、表格、分页顺序固定。
- 主要操作使用蓝色 `Button variant="default"`，普通操作使用 `Button variant="outline"` 或 `variant="ghost"`；红色仅用于删除等危险操作。状态颜色表达状态，不用于随意装饰操作按钮。
- 主机新增、编辑、克隆使用独立路由页面；复杂表单分节展示，支持取消、保存、错误重试和离页未保存确认。轻量信息与二次确认使用 shadcn-vue `Dialog` / `AlertDialog`。
- 使用 `useFeedback` 的 `notify`、`confirmAction`、`promptText`，不要调用浏览器原生 `alert`、`confirm`、`prompt`。删除确认必须写明对象及影响；取消不能发送写请求，提交期间防止重复操作。
- 密码、私钥等敏感内容不得写入浏览器持久存储或回显。保留已有权限、TLS 校验和目标指纹校验。
- 按操作频率分层：表格常用操作使用可辨识图标并提供准确的可访问名称和悬停／键盘 Tooltip；升级、部署、删除等低频操作适当收入“更多”菜单。手机端关键操作可保留简短文字，不得给所有图标机械加字、撑宽或撑高整行。
- 页面验收必须包含从侧栏切换的 SPA 场景，不能仅逐页刷新；读取失败不得显示为“暂无数据”，保留可重试的错误提示。RDP 下载前校验证书，明确区分服务／证书可达、平台授权和完整桌面登录。
- 手机端控件至少 44px，可读表单字号至少 16px；不得出现页面横向溢出。Tab、表单、按钮提供可访问名称与键盘操作。
- 修改后运行生产构建，并使用隔离演示接口验收桌面及手机页面、关键操作、失败及普通用户权限。线上验收不修改真实主机、凭据或授权记录。
