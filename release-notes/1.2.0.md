# FRP-AGENT v1.2.0

发布日期：2026-10-17

## 本版功能

- 主机资源统一管理：SSH、Portainer Docker、RDP，按用户 / API Key 授权，连接和操作审计。
- 原生 SSH 跳板、Docker HTTPS 网关、RDP 平台账号代登录；RDP 支持 NLA 与目标证书指纹自动获取、保存和后续校验。
- SSH 客户端版本扫描与升级、后台安装包同步、多平台脚本交付。
- 网页登录新增一次性验证码，2 分钟有效；失败后按 2、4、8 秒递增退避，最高 300 秒。Basic Auth 和旧配置令牌入口共用密码退避。

## 界面与文档

- 统一内容宽度、页面标题、表格、按钮和焦点样式，移除外部字体与头像请求。
- 手机底部快捷导航与全部功能面板，统一 44px 触控区域和表单字号。
- 全屏移动弹窗共用标题、滚动内容与操作栏布局；适配安全区和软键盘可视高度。
- 修复主机连接凭证 / 命令终端缺少完整滚动区域，以及主机编辑保存按钮被长表单挤出的问题。
- README 按实际功能重写，补齐主机访问、权限审计、客户端升级、登录保护与网关部署说明。
- 提供 1920 × 1080 脱敏演示截图，以及可复现的截图 / 移动布局验证脚本。

## 升级说明

1. 备份数据目录和部署配置，保留原有 `SSH_CREDENTIAL_SECRET`。
2. 检出 `v1.2.0`，执行 `docker compose up -d --build`；不假定镜像仓库已发布同名镜像。
3. 首次部署时在 `.env` 设置稳定的随机加密密钥。Compose 现支持从 `.env` 传入密钥和初始化账号。
4. RDP 默认关闭，启用前配置公网地址和 TLS 证书。首次 NLA 连接或修改密码后先登录网页。
5. 前后端需一起升级，网页登录改用 `/api/auth/captcha` 与 `/api/auth/login`；已有 Basic Auth / API Key 自动化接入仍可使用。

验证码与退避使用有容量限制的进程内状态，重启后重置；部署保持单 worker。反代只信任实际代理来源。RDP 网关的既有配置、限制与验收记录见主机管理文档。
