# FRP-AGENT v1.3.0

发布日期：2026-10-24

## 内置 FRP 与网页配置

- 镜像内置官方 frps 0.71.1，构建时校验 SHA-256；管理员可直接从网页启停，无需单独部署 frps。
- 首次进入管理界面提示一次部署方式，选择持久保存；后续在“服务器管理 → 内置 FRP 服务端”自行启用或关闭，默认关闭。
- 提供基础配置、安全设置、HTTP 回调插件和完整 frps.toml 编辑器。可仅校验原始配置，保存与重启保留原始文本和注释；修改表单保留插件、高级参数及不连续端口池。
- 默认生成随机连接 Token 和独立管理密码，Token 可查看、复制和修改；默认强制 TLS、限制代理端口，内部管理接口仅监听回环地址并要求认证，关闭调试分析和客户端详细错误。
- 支持 TLS 证书、客户端 CA、心跳与工作连接额外认证；平台生成的客户端配置同步携带 TLS 和额外认证选项。
- 配置先经官方 frps 校验再应用；拒绝过期原始草稿覆盖新配置，启动失败恢复旧配置，进程退出自动尝试重启，容器重启恢复已保存的启用状态。

## 代理与主机连接流量

- 代理列表与分组代理展示 frps 当日入站、出站字节、连接数和采集时间；数据为同步快照，服务重启可能清零。
- 主机资源增加流量统计，覆盖页面 SSH 命令、SSH/SFTP 网关、RDP 网关与 Docker 操作，可按主机、操作者、来源 IP、动作和时间筛选。
- 主机连接结束后入账，统计保留审计记录中的应用层字节；不含协议加密开销或远端容器自身网络用量。普通用户和 API Key 仅可查看自己的记录，旧记录显示未采集。

## 升级说明

- 推荐镜像：`registry.cn-shanghai.aliyuncs.com/numen/frp-agent:v1.3.0`，同时更新 `latest`。
- 升级前备份数据目录与部署配置，保留原有 `SSH_CREDENTIAL_SECRET`、认证和网关配置；启动时自动迁移数据库。回退旧版时使用升级前的数据备份。
- 内置 FRP 默认关闭，升级不会自动开启。需要启用时更新 Docker 端口映射：默认控制端口 `7000/TCP`、代理池 `6000–6099/TCP` 与 `UDP`；内部管理端口 `7500` 不对外映射。已有主机占用这些端口时先调整映射和允许范围。
- 修改启用配置会重启 frps 并短暂断开现有代理连接；更改 Token 后需同步更新客户端。
- 主机流量来自已保留审计记录，清理记录会减少累计；FRP 代理流量与主机访问流量分别计数，不能相加作为整机带宽。

- 后端 147 项自动化测试通过，包含官方 frps/frpc 的实际连接、数据传输、流量采集、安全拒绝、插件回调、配置回滚和恢复。
- 浏览器验证首次提示、启停、基础与原始配置、插件保留、草稿保护和移动端布局。
