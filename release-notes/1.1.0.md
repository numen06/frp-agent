## 本版亮点

### 安装包管理中心

新增独立的安装包管理模块，支持从 GitHub（fatedier/frp）自动同步各平台 frpc 二进制文件，也可手动上传自定义编译版本。提供按版本 / 平台筛选、一键生成安装与升级脚本的能力。

### 分组一键部署

分组管理新增「一键安装」功能，为分组生成 Linux Bash 和 Windows PowerShell 交付脚本。脚本会自动下载对应平台的 frpc 二进制、拉取配置文件并配置 systemd 服务，大幅简化客户端交付流程。

### 配置导入增强

- 支持通过 Web 界面上传 INI / TOML 配置文件导入
- 支持通过 API 以文本方式批量导入配置（JSON 格式）
- 新增分组级配置导入脚本

### API Key 管理

新增 API Key 模块，支持创建、查看、编辑和删除 API 密钥。API Key 可用于 Bearer Token 认证或 URL 参数认证，方便外部系统对接。

### 脚本模板自定义

安装包管理中新增脚本模板编辑功能，可自定义 Linux / Windows 平台的安装脚本和升级脚本模板，满足不同部署环境的定制需求。

### 其他改进

- 端口自动识别：从代理名称关键字（ssh、http、mysql、redis 等 40+ 种）自动识别本地服务端口
- 代理历史记录：记录代理状态变更，便于问题追溯
- 数据对比分析：对比 frps 实际代理与本地数据库的差异
- 默认密码安全：首次登录强制提示修改默认密码
- 前端 UI 优化：基于 Tailwind CSS 4 + Flowbite 重新构建，体验更现代

## 升级说明

### Docker

1. 备份 `data` 持久化目录
2. 拉取新版本镜像后重建容器，卷映射不变即可完成升级

```bash
docker pull registry.cn-shanghai.aliyuncs.com/numen/frp-agent:v1.1.0
docker stop frp-agent && docker rm frp-agent
docker run -d --name frp-agent -p 8000:8000 -v $(pwd)/data:/app/data registry.cn-shanghai.aliyuncs.com/numen/frp-agent:v1.1.0
```

### 源码部署

1. 拉取 `v1.1.0` 标签
2. 重新构建前端：`cd frontend && npm install && npm run build`
3. 安装后端依赖：`cd backend && pip install -r requirements.txt`
4. 重启后端服务

## 破坏性变更

**无**。本版本为增量功能更新，数据库结构自动迁移，无破坏性变更。
