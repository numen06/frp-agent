# FRP-AGENT v1.3.1

发布日期：2026-10-24

- 修复迁移旧 frps 原始配置时，较短的已有连接 Token 与管理密码被校验拦截的问题。管理员可在原始文件中保留旧凭据，使已有客户端继续使用原配置。
- 新建内置服务仍默认生成随机 Token、独立管理密码并强制 TLS；基础表单修改 Token 仍要求至少 16 字符。空凭据、非法 Token 和对外监听的内部管理接口仍被拒绝。
- 修改基础配置、保存原始文件与重启服务均保留已导入的旧凭据。新增回归验证覆盖凭据保留与基础表单的强度校验。
- 推荐镜像：`registry.cn-shanghai.aliyuncs.com/numen/frp-agent:v1.3.1`，同时更新 `latest`。升级前备份数据并保留原有凭据加密密钥。
