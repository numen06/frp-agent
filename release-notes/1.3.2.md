# v1.3.2

发布日期：2026-11-02

- 分组“查看代理”复用代理列表的手机卡片，统一筛选、操作与流量排版；修复弹窗长标题、按钮文字溢出、读取失败误示为空及过期请求覆盖。分组内新增代理默认使用当前分组。

- 内置 FRP 增加明确的启用／关闭操作，按已保存配置启停；关闭前说明连接中断影响，保留配置、Token 与未保存草稿。

- 全站手机端逐页验收：统一节点、安装包、密钥、凭证、授权、用户与日志卡片，筛选与搜索操作对齐，触控目标至少 44px；修复下拉搜索框及长选项溢出、旧弹窗主按钮白字透明底，补充列表与概览读取失败重试。节点编辑留空保留原密码及 Token，保存期间阻止重复提交并保留失败输入。

- 手机代理与分组使用独立等高卡片，长名称限制行数，信息、流量与操作分区；主机增加类型及最近检查状态筛选，服务端筛选后分页，进入详情或编辑再返回时保留筛选。
- SSH 主机新增 xterm.js 交互式 Web SSH，支持实时输入、Ctrl+C、Tab 和窗口缩放；复用执行权限、加密凭据与主机指纹，定期复查授权并限制会话时长和并发。会话审计仅记录连接及流量，不录制终端输入输出。
- 点击主机名称查看详情，卡片提供日志快捷入口；按当前主机查阅操作、连接日志、输出详情及流量，重置筛选仍保留主机范围，普通用户仅查询自身审计记录。
- 主机列表卡片固定高度、统一操作位置，长内容摘要显示；完整状态、指纹与连接说明移入详情弹窗，编辑、克隆与删除等操作收进菜单。
- 左侧“穿透服务”统一入口，页面分为“服务节点”和“内置服务”两个 Tab；内置服务仅管理员可见，首次配置引导同步更新。
- 修复从仪表盘等页面进入代理列表时，默认服务器未传递导致不发起查询的问题；读取失败与筛选无结果明确区分，提供重试和清除筛选。
- 表格常用操作采用带悬停／聚焦提示的紧凑图标，低频操作收入“更多”菜单，操作列固定在右侧；二级 Tab 统一选中态，手机主机资源 Tab 分行显示。
- RDP 下载前重新检查 TLS 与证书；证书变化显示持久错误及管理员处理入口。历史检查结果不再标为完整连接正常，审计区分平台认证通过、桌面连接成功和会话结束。

- 仪表板与运行维护分离，运行维护按资源监控、连接检查、RDP 防护分为三个 Tab，支持链接定位和键盘切换；仅在维护页面轮询运行数据。
- 主机新增、编辑、克隆改为独立页面；分节维护连接与凭据，保留列表筛选，提供未保存提醒、加载重试与保存错误提示。
- 导航改为可折叠左侧菜单，手机端使用抽屉导航；全站切换为 shadcn-vue / Reka UI，移除 Flowbite 和旧定制选择器、弹窗、菜单及浮动复制提示。
- 全站统一页面标题、卡片、表单、按钮与 Tab；删除及其他二次确认采用公共对话框，操作反馈采用统一通知，手机端危险操作确认使用紧凑弹窗。

- 管理员运行概览新增容器 / 应用资源、系统可见资源、限额、运行时长、24 小时趋势和连接质量；每分钟采样，保留 7 天，明确提示未知、过期和读取失败。
- FRP 默认每 60 秒同步，补齐 STCP 等代理类型和下线历史；请求失败保留上次状态，不再将失败当作空列表。旧版不支持的附加类型不误标离线。
- 每 5 分钟检查已注册 SSH 代理的实际握手，区分代理在线与目标握手正常；不发送登录凭据。
- 内置 FRP 通过实际本机监听地址检查握手，避免公网 NAT 回环导致误报；页面标明检查视角，并可展开全部握手异常。
- RDP 客户端握手失败纳入来源封禁，重复错误每分钟汇总，并分别统计握手失败、认证失败、拦截和桌面连接成功；网关上游异常不计入客户端封禁。

升级前备份数据和部署配置，保留 `SSH_CREDENTIAL_SECRET`。已有部署显式设置的 `SYNC_INTERVAL_SECONDS` 优先，需要在部署配置中改为 `60` 才会采用新周期。更新会重启容器并中断现有网关及内置 FRP 连接，升级后核对代理重连和目标服务握手。新资源趋势从升级后开始积累，无法补回此前未采集的数据。
