# FRP-AGENT v1.2.2

发布日期：2026-10-17

- 管理列表和远程选择器统一默认每页 20 条，上限 100 条；补齐服务器、主机、授权、用户、凭据、密钥、端口、同步历史和审计分页，修复跨页选择与末页删除后的回退。
- 访问审计新增筛选、命令输出详情、批量删除和按保留天数清理；清理先预览再确认，维护权限仅限管理员，并保留维护记录。
- 修复代理列表“添加”菜单漂到左上角，统一代理、分组和安装包浮动菜单定位、视口边界和 Escape 关闭。
- 分组新增默认生成 SSH / HTTP / Docker 标准代理并直接打开配置；非空分组删除需二次确认，确认后删除配置、清理关联状态并释放端口，不再移入“其他”。
- 分组与默认代理创建整体回滚；删除前校验预览数量和运行中任务，避免误删变化中的配置。
- 手机端统一分页、选择器与弹窗操作区；更新 1920 × 1080 虚构演示截图。
- 修复左上角 Logo 的 FRP 与 -AGENT 间距，包含此前移动端、验证码、登录错误退避与 RDP 修复。

推荐镜像：`registry.cn-shanghai.aliyuncs.com/numen/frp-agent:v1.2.2`，同时更新 `latest`。升级前备份数据和部署配置，保留原有凭据加密密钥；默认 Compose 执行 `docker compose pull`、`docker compose up -d --no-build`。

旧数组 API 现在默认最多返回 20 条，自动化接入需改用 `page` / `page_size` 逐页读取。Docker / Portainer 容器源和历史任务 JSON 在服务端仍需完整读取，再分页返回。完整覆盖范围与接口说明见 [分页文档](../docs/pagination.md)。

验证：114 项后端测试通过，前端构建通过；桌面 / 手机多页交互、分组创建与二次删除确认、审计详情及清理预览通过；4 种屏宽与 22 类弹窗完成可操作性检查。截图全部来自隔离演示接口。
