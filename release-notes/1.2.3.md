# FRP-AGENT v1.2.3

发布日期：2026-10-17

- 在“主机资源”补齐管理员专用的“凭证管理”入口，统一管理 SSH / RDP 和 Docker / Portainer 凭证。
- 支持默认每页 20 条、搜索、新增、编辑、私钥文件上传与确认删除，适配手机全屏弹窗和固定操作区。
- 密码、私钥、私钥口令、sudo 密码、Portainer API Key 与 CA 证书仅显示设置状态；编辑留空保留，支持显式清除可选内容。
- 正在被主机、代理客户端或运行中任务使用的凭证禁止删除，已完成任务历史保留；RDP 使用中的密码凭证禁止切换成 SSH 私钥认证，认证必需内容不能清空。
- 修复主机内嵌 SSH 凭证保存后再次编辑丢失编辑状态，以及切换凭证时旧请求覆盖选择的问题。
- 更新功能说明与 1920 × 1080 虚构演示截图，截图不读取生产数据。
- 主机接入文档统一使用示例域名，移除真实部署地址。

推荐镜像：`registry.cn-shanghai.aliyuncs.com/numen/frp-agent:v1.2.3`，同时更新 `latest`。保留原有数据目录、凭据加密密钥和网关配置，备份后拉取镜像重建容器即可。
