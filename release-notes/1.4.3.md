# 1.4.3

- README 改为使用指南，补充 Docker 部署与升级、FRP 代理管理、主机连接和 macOS VNC 的操作路径。截图用本版构建和隔离演示数据重新生成。
- 主机资源默认打开连接列表，可按主机或分组筛选。新增连接时可选择已有主机，也可以同时创建主机。
- macOS VNC 支持内网或内置 FRP 转发直连，SSH 隧道可选。远程桌面提供手机键盘入口，可发送锁屏密码及回车。

Docker 镜像使用 `registry.cn-shanghai.aliyuncs.com/numen/frp-agent:1.4.3` 或 `latest`。升级时备份数据目录和部署配置，保留原 `SSH_CREDENTIAL_SECRET`。[升级步骤](../README.md#升级已有部署)
