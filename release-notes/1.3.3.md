# v1.3.3

日期：2026-11-05（dev）

- 新增 VNC / macOS 主机管理，复用凭据、连接授权、有效期、连接测试、日志和流量统计，提供基于 noVNC 的浏览器远程桌面。
- 浏览器连接强制 HTTPS/WSS 及同源检查；VNC 通过已登记指纹的 Mac SSH 通道访问回环端口。目标密码由服务端完成认证，不向客户端返回，不开放公网 VNC 监听端口。
- 拒绝目标无密码认证，限制会话并发、输入大小和最长时长；定期复核授权、账号、主机及凭据变化，撤销后断开。审计不记录桌面内容、键盘输入和密码。
- 增加 `vnc_ssh_host_id` 的兼容迁移，阻止删除仍被 VNC 引用的 SSH 主机及改变其类型。传统 VNC 密码必须为 1–8 位 ASCII，需在 Mac 开启 VNC 密码控制；暂不支持仅 Apple ARD 账号认证的配置。
- 同步未提交的 v1.3.2 主机详情、Web SSH、shadcn-vue 界面、自动发现与运行维护实现，相关说明见 [1.3.2](1.3.2.md)。
- 后端 VERSION、前端包版本、Docker 默认构建版本及 OCI 版本标签统一为 1.3.3。构建时校验镜像版本与后端 VERSION；Compose 默认使用固定版本，可通过 `FRP_AGENT_IMAGE` 指定开发镜像。固定版本仓库镜像需单独发布，推送 dev 不会自动发布镜像。

## 验证

本地完整后端测试为 208 项通过、4 项按环境跳过。NUC Docker 的隔离容器完成 89 项相关回归，以及真实 HTTPS/WSS → SSH → VNC 桌面帧链路，验证越权、同源、授权撤销、错误指纹、错误密码拦截及审计脱敏。页面完成桌面、390px / 320px 手机隔离联调。协议目标为测试夹具，真实 Mac 屏幕共享仍需实机验证。

## 升级

备份数据与部署配置，保留原 `SSH_CREDENTIAL_SECRET`。VNC 须关联已启用并经可信渠道核验 SSH 指纹的 Mac SSH 主机；无需为用户授予该 SSH 主机的执行权限。反向代理需正确转发 WebSocket、原始 Host 与可信 HTTPS 协议头。详细步骤见 [macOS VNC 接入说明](../docs/vnc-macos.md)。
